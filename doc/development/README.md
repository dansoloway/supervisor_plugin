# Development Tools

This folder contains development, testing, and debugging tools that are not needed for production.

## Contents

### Seed Content Scripts
- `create-*.php` - Scripts for creating seed/test content
- `seed-content.php` - Main seed content script

### Debug Scripts
- `debug-*.php` - Debugging utilities for troubleshooting

### Migration Scripts
- `migrate-*.php` - Database migration scripts
- `update-*.php` - Update/cleanup scripts

### Test Files
- `tests/` - Test suite directory
- `run-tests.php` - Test runner

### Other
- `logs/` - Log files directory
- `supervisor-plugin-new-design.zip` - Archive file

## Usage

These files are kept for reference and can be moved back to the root directory if needed for development or debugging.

**Note:** If you need to use `debug-updates-dates.php`, update the path in `supervisor-plugin.php` or temporarily move it back to the root directory.
